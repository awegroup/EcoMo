# Data directory

## Excel source files (development artifacts)
The .xlsx files in this directory were the original input format for ECOMo.
They have been converted to YAML (config/test/) and are no longer needed at
runtime. They are kept here for reference and can be archived or deleted once
the YAML files are verified.

## AWESPA output files
aep_results.yml and power_curves.yml are example AWESPA outputs used for
testing the AWESPA-connected mode.
